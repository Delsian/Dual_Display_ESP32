PARROT / ESP32 VOICE COMPANION

Online services

Dashboards, billing, quotas, and logs for the cloud voice workflow.

Sign in and select the correct Cloudflare account or Google Cloud project. Gemini and Cloud TTS may use different projects. Links below do not contain credentials.

Cloudflare Workers

Hosts the parrot backend and device authentication.

  • Worker dashboard, deployments & secrets Account → Workers & Pages → parrot. Use Settings for secrets and Edit code for deployment.
  • Worker logs & metrics Open parrot → Observability. Historical logs depend on logging configuration; use live logs when available.
  • Cloudflare billing Account → Billing. Account-specific links require your account ID.
  • Parrot health endpoint Checks that required secrets exist; does not verify provider credentials or remaining quota.
  • Workers pricing
  • Cloudflare service status

Gemini / Google AI Studio

Understands recorded speech and generates the text answer for /ask.

  • AI Studio
  • Gemini API keys & projects
  • Usage dashboard
  • Active rate limits & quotas Check the selected model and project when Gemini returns HTTP 429.
  • Gemini project billing Select the billing account linked to the Gemini key's project.
  • Gemini API pricing
  • Request logs, where enabled Check AI Studio's logging controls. Usage metrics are not a transcript of every request; provider payloads are not logged by this Worker.
  • Gemini API service status

Google Cloud Text-to-Speech

Standard voices generate audio for /speak and /test-speech.

  • Enable / manage Cloud TTS API
  • API keys & restrictions
  • TTS requests, errors & latency
  • TTS quotas
  • Billing, cost reports & budgets Select a billing account, then Reports or Budgets & alerts. Budget alerts do not cap spending.
  • Cloud Logging / Logs Explorer Select the TTS project. Available entries depend on supported audit logs and logging configuration; synthesized audio and request text are not guaranteed to appear.
  • TTS pricing & free allowance
  • Voice catalog
  • Google Cloud service status

Device logs: ESP32 audio, download, conversion and connection timings are available through the local serial monitor, not an online dashboard.
